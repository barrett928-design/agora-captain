## SOS — Step-by-Step Procedure

**Before using SOS:** Device must have active satellite subscription. Test before each passage outdoors.

### Standard SOS
1. Lift the protective cap over the SOS button
2. Press and hold the SOS button
3. Wait for the SOS countdown to complete
4. Device sends default message to Garmin Response with your GPS location
5. **Reply to the confirmation message** — this tells Garmin Response you can communicate
6. If you do NOT reply, they still initiate a rescue
7. For first 10 minutes: location update sent every **1 minute**
8. After 10 minutes: location update every **10 minutes** (moving) or **30 minutes** (stationary)

### Custom SOS Message
1. Select **SOS > Emergency > Write SOS**
2. Select **Message:** to compose custom text
3. Select **Send Message**
4. Reply to confirmation from emergency response

### Canceling SOS
1. Lift protective cap, hold SOS key
2. Select **Cancel**
3. Wait for confirmation message from emergency response — device returns to normal

## Getting Started

### First-Time Setup
1. Create account and select satellite subscription at **inreach.garmin.com**
2. Turn on device (hold Power key)
3. Follow on-screen instructions
4. Go outdoors to open area with clear sky view
5. Wait for Iridium satellite communication — activation can take up to **20 minutes**

### Testing the Device (Do Before Each Passage)
1. Select **Test > Test**
2. Wait for confirmation message — device is ready when confirmed

### Pairing with Earthmate App
1. Install Earthmate app on phone
2. On inReach: **Settings > Bluetooth > Pair Device > Pair Device**
3. Devices auto-connect when on and within range (10 ft / 3 m)

## Status LED Reference

| LED | Status |
|---|---|
| Flashing green | Unread message |
| Flashing red | No satellite view OR below 10% battery |
| Alternating red/green | Device in SOS mode |
| Alternating red/green rapidly | Canceling SOS rescue |

## Tracking

- **Start:** Select **Tracking > Start** (optionally send share message to family)
- **Stop:** Select **Tracking > Stop**
- Track points appear on your MapShare web page for friends/family to follow
- When storage is full, device overwrites older track points but retains lower-detail line

### Maximize Battery Life While Tracking
- Enable **Extended Tracking** (Settings > Tracking) — enters sleep mode between track points; disables Bluetooth and detailed tracking
- Reduce **Send Interval** and **Log Interval**
- Turn off Bluetooth when not needed
- Reduce backlight brightness/timeout

---

## Weather (Marine Forecasts)

The inReach can request marine weather forecasts — useful for passage planning offshore:

1. Select **Weather > New Location** (or use current location)
2. Select **Get Forecast**
3. To get marine forecast: **Weather > Marine > Marine > Enabled**
4. For best results, request marine forecast for locations away from shore over open water

Weather forecasts incur data usage charges. Check your subscription plan.

## Messages

- Sends/receives text messages over Iridium satellite network
- Can send to: SMS phone numbers, email addresses, other inReach devices
- Every message includes your location details
- Default listen interval for new messages: **10 minutes** (adjustable)
- Force check: **Select Check > Check Now**

### Including Location in a Message
1. New Message > enter recipients
2. Select the location icon to include GPS coordinates

## Navigation Features (Explorer+ only)

- Routes: create at inreach.garmin.com, navigate from device
- Waypoints: save locations, navigate to them
- Map: shows location, messages, waypoints, track line
  - Explorer+ shows streets, POI, topographical info
- Direct routing only (not road routing)

## Device Care

- **Rinse with fresh water after salt water exposure** — critical for longevity
- Avoid: chemical cleaners, solvents, insect repellents (damage plastic/finishes)
- IPX7: withstands accidental immersion 1m for 30 min — NOT for extended submersion
- After submersion: wipe dry and air dry before charging
- Before charging: dry USB port and weather cap thoroughly to prevent corrosion

---

## Troubleshooting

**Device not responding:** Hold Power key until device turns off, then hold Power to restart. Does not erase data or settings.

**Restore factory settings:** Settings > Recovery Options > Restore Factory Settings

**View device info (IMEI, firmware):** Settings > About This Device

## Notes for Agora

- 2× units on board: mount to inflatable lifejackets; wear on all offshore passages
- Earthmate app pairs via Bluetooth — download NOAA nautical charts before departing to areas with poor connectivity
- Test before leaving each major port — send a test message to confirm subscription is active
- Register at beaconregistration.noaa.gov (for PLBs/EPIRB — inReach uses Garmin Response, not NOAA)
- For passage tracking, start tracking when leaving a harbor — family can follow at MapShare page
- Extended tracking mode (30-day battery) suitable for slow passages; default mode recommended for active offshore sailing
