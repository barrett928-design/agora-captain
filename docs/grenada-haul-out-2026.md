- [ ] Inspect/replace primary Racor filter (easier afloat)
- [ ] Note current Yanmar fuel filter hours (due at 250 hrs — 8 spares in Salon Seat Drawer)

## At the Yard / On the Hard

### Hull Below Waterline
- [ ] Pressure wash immediately after haul while still wet
- [ ] Full hull inspection — blisters, osmosis, impact damage
- [ ] Inspect all through-hull fittings
- [ ] **Exercise all seacocks** — must move freely, no exceptions. Seized seacocks are a serious safety issue
- [ ] Repack or rebed any stiff seacocks
- [ ] Close and mark all seacocks for storage
- [ ] Inspect keel bolts while accessible
- [ ] **Replace hull zincs** (due annually or at 50%)
- [ ] Inspect rudder pintles, gudgeons, and bearings
- [ ] Inspect shaft seal and cutlass bearing
- [ ] Inspect Max Prop — confirm pitch setting H (front/big E, back/small); replace shaft zinc
- [ ] **New bottom paint** — ablative last done Nov 2025 (~7 months in tropical waters will have consumed most of it)

### Hull Above Waterline *(planned)*
- [ ] Compound hull above waterline
- [ ] Wax after compounding
- [ ] Touch up gel coat chips (Barrett — in progress)
- [ ] Inspect and re-seal hull-deck joint if showing wear

### Deck & Topside
- [ ] Check all deck hardware — cleats, stanchions, chainplates for loose fasteners
- [ ] **Clear all cockpit drains** — Grenada rainy season June–September; a blocked drain is how boats sink on the hard
- [ ] Inspect and reseal any suspect deck penetrations
- [ ] Inspect companionway hatch seals
- [ ] Install companionway cover and hatch covers (UV and rain protection)
- [ ] Replace windlass bolt *(open project — easy to do on the hard)*

### Rigging *(considering — this is the ideal time)*
- [ ] Standing rigging full inspection: broken strands, swage cracks, corrosion at chainplates, toggle and turnbuckle condition
- [ ] Check mast base and step for corrosion
- [ ] Running rigging: inspect halyards and sheets for chafe
- [ ] Service winches if approaching 2-year mark
- [ ] **Remove sails and store below or ashore** — Grenada UV June–September is punishing, and removing them also reduces wind load and theft risk

## Electrical & Batteries

- [ ] **Confirm shore power situation with yard** (see critical items above)
- [ ] If 120V available: connect shore power, verify Victron Multiplus charger settings:
  - Absorption: 14.2–14.4V
  - Float: **DISABLED** (or max 13.5V if must be set)
  - Temperature compensation: **0 mV/°C — DISABLED**
  - Equalization: **NEVER**
- [ ] If only 220V available: use ProNautic 1260P on 220V shore power as the charger (it handles 100–250V); **do not connect the Multiplus to 220V**
- [ ] Download and review SmartShunt data before departure — note SOC trends and any anomalies
- [ ] Turn off all non-essential DC loads: instruments, AIS, chartplotter, VHF (leave bilge pump ON)
- [ ] **Leave bilge pump float switch armed** — rain will collect in cockpit and find its way to the bilge even on the hard
- [ ] Disconnect engine start battery switch if engine won't be run

## Interior

### Ventilation *(most important thing for a tropical layup)*
- [ ] Install solar-powered ventilators on hatches — without these you'll return to a mold disaster
- [ ] Leave all interior locker and drawer doors open
- [ ] Leave cabin doors and head doors open
- [ ] Prop settee cushions and mattresses vertically for airflow underneath
- [ ] Leave ceiling panels open if possible

### Mold & Mildew
- [ ] Wipe all surfaces with dilute bleach or mildew treatment before leaving
- [ ] Place DampRid or equivalent moisture absorbers throughout — ask boat watcher to replace monthly
- [ ] Empty and clean refrigerator; leave door propped open
- [ ] Remove all food, especially anything organic or in cardboard

### Pest Prevention *(boatyards in tropics)*
- [ ] Install rodent guards on shore power cord where it enters boat
- [ ] Stuff stainless steel wool or pot scrubbers in exhaust outlets to block nesting
- [ ] Set bait blocks or traps in the bilge and lockers (coordinate with boat watcher to check)
- [ ] Seal any gaps in cockpit locker lids with tape

### Plumbing
- [ ] Pump out holding tanks completely, flush with fresh water
- [ ] Treat fresh water tanks with dilute bleach, flush through all taps
- [ ] Close all seacocks (confirm each one)
- [ ] Inspect head vent hoses — blocked vents cause pressure buildup and seal failure
- [ ] Note tank meter readings before departure (installed Mar 2025)
