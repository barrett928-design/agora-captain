# Autopilot — Raymarine EV-1 (Hydraulic)

## Hardware
- **Course computer / sensor:** Raymarine EV-1
- **Control head:** Raymarine P70 Pilothead
- **Drive:** Hydraulic ram + hydraulic pump (NOT a linear drive)

## Known Issues
- Autopilot disengaging — open project
- AIS signal loss (Raymarine AIS650) being investigated at the same time
- These may share a root cause: NMEA 2000 network health (termination, bus power, device conflict)
- Check NMEA 2000 backbone first before replacing components

## Maintenance (Before Each Passage)
- Verify autopilot engages and holds course
- Check hydraulic fluid level and lines for leaks
- Listen for unusual pump noise

## Notes
- The Raymarine Linear Drive installation manual in the docs folder is reference material and does NOT reflect what's installed on Agora
